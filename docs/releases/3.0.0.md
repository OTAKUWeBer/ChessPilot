# ChessPilot 3.0.0 — Rust, Flutter and Android

ChessPilot 3.0.0 rebuilds the desktop app around a Rust core and Flutter interface, and brings capture, local analysis and movable touch controls to Android.

## What's new

- **Windows, Linux and Android:** native capture and move input, with a shared Rust analysis pipeline and Flutter controls.
- **Local board detection:** the bundled ONNX model runs on in-memory captures, with refined search for difficult board sizes.
- **Stockfish setup:** desktop downloads a CPU-compatible official release when missing. Android includes its compatible engines and network. Gameplay works offline after setup.
- **Game tracking:** legal opponent-reply tracking, castling-right updates after confirmed king/rook moves, cancellable waits, and clearer checkmate/stalemate messages.
- **Compact phone controls:** a movable overlay with Play, Auto, Stop and Exit; desktop shortcuts stay on desktop. Android defaults to depth 10; desktop defaults to 15.
- **Desktop downloads:** Windows installer and portable ZIP, plus Linux portable executable, AppImage, DEB and per-user installer. Supporting libraries and the detector model are included.

## Choose a download

| File | Platform | How to use |
| --- | --- | --- |
| `ChessPilot-3.0.0-windows-x64-setup.exe` | Windows 10 / 11 x64 | Run the per-user installer. |
| `ChessPilot-3.0.0-windows-x64.zip` | Windows x64 portable | Extract the whole ZIP and run `chesspilot.exe`; keep its files together. |
| `ChessPilot-3.0.0-android-arm64.apk` | Android ARM64, Android 7+ | Install the APK, enable touch control and approve whole-display sharing. |
| `ChessPilot-3.0.0-linux-x86_64` | Linux x86_64 portable | Make executable and run; no installation or FUSE needed. |
| `ChessPilot-3.0.0-linux-x86_64.AppImage` | Linux x86_64 | Make executable and run; use `--appimage-extract-and-run` if FUSE is unavailable. |
| `chesspilot_3.0.0_amd64.deb` | Compatible Debian / Ubuntu / Mint x64 | Install with `sudo apt install ./chesspilot_3.0.0_amd64.deb`. |
| `ChessPilot-3.0.0-linux-x64-setup.run` | Linux x86_64 per-user install | Run with `sh`; installs a menu launcher without `sudo`. |

Linux release packages use Ubuntu 22.04 as the build baseline. X11 requires XTEST; supported wlroots Wayland sessions need `grim`, screencopy and virtual-pointer protocols. GNOME/KDE Wayland portal automation is not implemented. Graphics drivers, architecture and system-library compatibility still matter; these packages do not support every distro or compositor.

## Before the first game

Keep the full board visible, choose your color and applicable castling rights, then use Play or Auto on your turn. Stop pauses automation; Android Exit also ends capture and closes the engine. Start a new session after a finished game.

Linux portable/AppImage/DEB packages keep Stockfish and options in user data. Windows bundles and the Linux `.run` installation keep them beside the app. Existing options are preserved; a screenshot cannot reveal king/rook moves made before tracking began.

**Signing:** the Windows installer is unsigned. This Android APK uses the maintainer's development signing key; future APK updates must use the same key to update it in place. The app does not require Flutter, Rust, Python or build tools to be installed.
