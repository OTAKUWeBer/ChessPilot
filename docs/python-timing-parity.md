# Python timing ledger

This inventories every `sleep` and `QTimer.singleShot` call in the unchanged Python source. Each row identifies its native destination or an explicit control-flow change. A recorded replacement is not a claim that the Python schedule is copied literally. In particular, no uncertain move is sent twice merely to keep an old retry loop.

Gameplay waits execute off Flutter’s UI thread and are cancellation-aware. Android gestures use callbacks and currently use 50 ms taps / 200 ms drags, with 40 ms between completed click-mode taps; these require the user’s later device calibration. X11 additionally preserves PyAutoGUI’s implicit 100 ms pause (drag 300 ms; click 240 ms); its 50 ms moveTo is below PyAutoGUI’s interpolation threshold.
