# Contributing to ChessPilot

Use [BUILDING.md](docs/BUILDING.md) to prepare a development environment and [TESTING.md](docs/TESTING.md) for checks and opt-in integration prerequisites. Runtime ownership and platform boundaries are in [ENGINEERING.md](docs/ENGINEERING.md). Versions use the single command in [RELEASING.md](docs/RELEASING.md); do not edit generated runner/Gradle version files.

Keep changes focused, preserve user configuration/assets and describe relevant validation and remaining limits in your pull request. Never run input tests against an unrelated window. Do not commit binaries, SDK caches, personal screenshots, logs or signing credentials.
